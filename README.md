# Online Bus Booking System

## Description
A comprehensive web-based application for booking bus tickets online. This ASP.NET project provides an efficient platform for travelers to search, select, and book bus tickets while offering administrators tools to manage bus services, routes, schedules, and bookings.

## Features
- User registration and authentication
- Bus search functionality based on source, destination, and travel date
- Seat selection interface
- Secure online booking and payment processing
- Booking history and ticket management for users
- Administrative dashboard for managing buses, routes, and bookings
- Booking reports and analytics for administrators

## Technologies Used
- ASP.NET Framework
- C#
- SQL Server Database
- HTML5, CSS3, JavaScript
- Bootstrap for responsive design
- iTextSharp for PDF generation

## Setup Instructions
1. Clone the repository to your local machine
2. Open the solution in Visual Studio
3. Restore the database backup or run the SQL scripts to create the database
4. Update the connection string in the Web.config file
5. Build and run the application

## Usage
### For Users:
1. Register or login to your account
2. Search for buses by entering source, destination, and travel date
3. Select your preferred bus and choose available seats
4. Enter passenger details and make payment
5. Download or print your e-ticket

### For Administrators:
1. Access the admin panel using admin credentials
2. Manage bus services, routes, and schedules
3. View and handle bookings
4. Generate reports and analyze booking data

## Project Structure
- **Admin/** - Contains administrative modules and functionality
- **css/** - Stylesheet files for the application
- **images/** - Image assets used in the application
- **bin/** - Compiled binaries and dependencies
